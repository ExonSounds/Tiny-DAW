# Tiny DAW
*Goal is to create a fully functional and open-sourced DAW, which is easy to navigate through by anybody.*
*Apologies though for even vibe coding this for those who think I should have not. I do not wish to waste my life to create such a complex program. Yet the world and the producers deserve an alternative program, which performs the same as the best DAWs out there.*

- Please report any bugs that do appear.
- Desired features are very welcome!

A bit more detailed README is located in the release .zip file. 

# If you are reporting a bug.
- Please provide information about what is not working / is bugged out
- How to recreate that issue
- A fix suggestion if you do know how to fix it.
